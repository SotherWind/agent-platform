# 优选商城优惠券与促销活动规则

## 优惠券类型

1. 满减券：满 X 元减 Y 元（如满 199 减 30）。
2. 折扣券：指定商品按折扣结算（如 9 折券，单笔最高抵 50 元）。
3. 无门槛券：无使用门槛，直接抵扣（一般面额 5-20 元）。
4. 运费券：抵扣单笔订单基础运费（不抵偏远地区加收部分）。

## 使用规则

- 有效期：以券面标注为准，到期自动失效，过期不补发。
- 叠加：单品可与一张平台券、一张店铺券叠加；同类两张券不可叠加。
- 分摊：多商品订单使用满减券时，优惠金额按商品价格比例分摊到各商品，退款时按分摊额计算退款。
- 计算顺序：商品折扣 → 店铺券 → 平台券 → 积分抵扣 → 运费券。

## 领取与退回

- 领取：领券中心、商品页、会员专享、任务奖励（签到、评价）。
- 退货退回：全额退款且券在有效期内 → 自动退回；已过期 → 不退（退款金额为实付金额）。
- 撤销订单：未付款订单取消后，订单使用的券立即退回。

## 大促活动说明

- 618/双11 跨店满减：每满 X 元减 Y 元，可跨店叠加，不与「每满减」券重复叠加。
- 限时秒杀：每人每场次限购 1-2 件，以商品页标注为准；秒杀订单支持正常售后，价保按《价保规则》执行（秒杀价本身不支持价保）。
- 预售定金：定金支付后未在尾款期支付尾款的，定金不退（商家未履约的除外，定金双倍退回）；尾款支持与定金一起按原支付渠道退回的条件见商品页说明。

## 异常与风控

- 券不可转让、不可兑换现金。
- 通过异常账号（机器批量注册、刷单账号）领取的券，平台有权冻结与回收。
- 活动解释：活动最终解释权在法律允许范围内归平台所有；对规则有疑问的，联系客服核实订单维度的实际优惠明细。
